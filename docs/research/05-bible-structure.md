# Bible Structure

**The bible gets straight to the point: statement first, then the graphic that proves it.** It runs from the whole to the part.

## 1 Order

| No. | Chapter        | Core statement                                                      |
| --- | -------------- | ------------------------------------------------------------------- |
| 0   | Guiding vision | We build on the existing city: no streets, upward, in closed loops. |
| 1   | City           | The city retains, converts, extends; elevated walkways connect it.  |
| 2   | Forms          | A house stacks a few forms: stock, frame, plug-ins, crown.          |
| 3   | Grid           | Every grid ends in quads, so every house fits every plot.           |
| 4   | Growth         | Paths first, then blocks; the same seed yields the same city.       |
| 5   | Color          | Color is meaning: 75 % ground, 20 % function, 5 % accent.           |
| 6   | Material       | Color says what it is; material says how deep it sits.              |
| 7   | Focus          | At most three flows appear in color.                                |
| 8   | Interface      | Icons and controls speak the language of the city.                  |
| 9   | Principles     | Each rule has a player side and an engine side.                     |
| W   | Workshop       | Lab, archive and sources.                                           |

## 2 Ground rules

1. One content type has one layout form.
2. Every piece of information appears once.
3. A rule sits on its object, as a do/don't pair.
4. Content separates sections, not layout.
5. One statement per section; the heading is the statement.
6. No jargon on the main level.
7. The entry needs no heading.
8. The demo shows the effect; the text says why.

## 3 Information design

Method: write the statement, find the proving comparison, pick one pattern, label directly, cut the rest. Patterns: mapping list, classification card, share and flow, comparison, scale, sequence, map and section, demo with context. Tables appear only in deep dives.

Page grid: 12 columns from 1200 px, 8 from 768 px, 4 below. Text runs at most 68 characters. Demo controls stand right of the image, at most three sliders.

## 4 Page types

| Type           | After title, entry and opener image      | Used for                   |
| -------------- | ---------------------------------------- | -------------------------- |
| Guiding vision | Three guiding statements, chapter cards  | Start page                 |
| Rule chapter   | One main graphic, 3–5 statement sections | City, Color                |
| Vocabulary     | Card set, one combination section        | Forms, Material, Interface |
| Demo chapter   | Lead demo, 2–3 short sections            | Grid, Growth, Focus        |
| Reference      | Index with links, detail in deep dives   | Principles, Workshop       |

## 5 Chapter by chapter

- **City:** four interventions on stock, elevated walkways, rain stays in the district.
- **Forms:** twelve forms; the crown shows the use.
- **Grid:** lead demo; corners decide the module; deforming has limits.
- **Growth:** fields steer direction; houses arise by splitting.
- **Workshop:** the lab runs the full simulation and one experiment per principle.
