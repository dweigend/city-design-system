## Design-Specific Binding Additions (V for Adoption)

Basis: [95 (01-universal-grid)](../../research/01-universal-grid.md), [96 (02-geometry-principles)](../../research/02-geometry-principles.md), 100 (private lab) and their current result limitations. Architecture ideas or individual measurements are not an overall sign-off.

- **Reproducibility:** define algorithm version, seed normalization, PRNG, stream splitting, traversal/tie order, and draw consumption. Identical inputs and declared runtime environment produce identical data. Continuation stores RNG state, not merely seed. Rendering, color selection, and observation consume no domain draws. Claim cross-platform bit-exactness only after proof.
- **Units and coordinates:** distinguish world, carrier/UV, grid, renderer, and screen space. Document origin, handedness, axes, vertical direction, angular unit, length unit, and transforms. Camera never changes world coordinates. Known points and rotations as contract probes.
- **Numerics:** derive tolerances from scale, unit, and operation; no global magic epsilon. Orientation and intersection decisions via robust predicates; define degenerate cases, `NaN`/`Infinity`, and boundary membership. Robust predicates do not replace a domain minimum frontage or area rule.
- **Invariants:** stable IDs, valid adjacency, orientation, unfolded embedding, positive areas, reachable accesses, and declared conservation quantities per operation. Transactions validate candidates before commit; no-op, sharing, undo, and error atomicity explicit. UV identity does not guarantee preserved frontage width.
- **Grid-agnostic topology:** IDs and adjacency independent of geometry and embedding. Algorithms declare actually supported grids; quad-specific assumptions visible. Morph without topology change only within validated bounds; otherwise declared event with hysteresis instead of silent re-identification.
- **Rendering as projection:** data describes geometry and material headlessly. `scene/` translates to three.js and owns GPU resources including `dispose`. Never recompute topology from meshes; frame rate changes no domain rules. Selection sends ID/action, not mesh mutation as state change.
- **Color/material contract:** typed semantic palette and material descriptors with value range, color space, alpha, roughness/metalness semantics, and conversion point. UI chrome and scientific data colors separated. No renderer objects in `data/` or `logic/`. Same material key yields defined parameters; color change regenerates no structure. Check color vision deficiency, contrast, and additional shape/text encoding.
- **Bible page:** rule → purpose → executable demo → metric with unit/budget → source and status. Interventions, seed, and reset visible; state boundary case and non-goal. Demo is a consumer of the catalog contract, containing no domain logic or CSS of its own.
- **Research:** question, authority/status, hypothesis, method, revision/environment, inputs/seeds, metrics, result, limitations, decision, and sources. Author decision separate from measurement finding. One permanent fact owner; do not rewrite historical findings.
- **Experiments:** throwaway code outside the product tree; fix end and deletion time in advance. After 100, bounded experiments, warmup and repeated runs with median or p95, scenes S/M/L, memory baseline, and device details. Only condensed metric tables and selected figure plates go into research; no raw data dumps. Comparison plates keep seed, model time, camera, and scale constant; label deviations. Blocked GPU/browser evidence stays open.
